# Typography Guidelines

Typography defines the voice, clarity, and rhythm of our digital products.

## Official Font Families

1. **Latin Interface & Headings**: `Inter Variable`
   - Clean, highly legible neo-grotesque sans-serif optimized for screens and high-density user interfaces.
   - Weights in use: `400` (Regular), `500` (Medium), `600` (Semi-bold), `700` (Bold).

2. **Code & Terminal**: `JetBrains Mono` or system monospace font
   - Monospaced typography with clear distinction between `0` and `O`, `1` and `l`.

3. **Khmer Language Content**: `Kantumruy Pro` / `Preahvihear`
   - Clean Khmer script pairing harmoniously with Latin heights and strokes.

## Type Scale Hierarchy

| Element | Size | Weight | Line Height | Usage |
| :--- | :--- | :--- | :--- | :--- |
| **Hero Title** | `2.5rem - 3.5rem` (`text-4xl` / `text-5xl`) | Bold (700) | Tight (1.1) | Main landing page headline |
| **Heading 1** | `2.0rem` (`text-3xl`) | Bold (700) | Snug (1.25) | Top-level document titles |
| **Heading 2** | `1.5rem` (`text-2xl`) | SemiBold (600) | Snug (1.3) | Section headers |
| **Heading 3** | `1.25rem` (`text-xl`) | SemiBold (600) | Normal (1.4) | Subsection headers |
| **Body Text** | `1rem` (`text-base`) | Regular (400) | Relaxed (1.65) | Long-form reading paragraphs |
| **Caption / Meta** | `0.875rem` (`text-sm`) | Medium (500) | Normal (1.5) | Badges, tooltips, table cells |
